# Sanggala Corridor Project - Dashboard

🔗 **Live site:** https://gis-carbonx.github.io/dashboard/

Dashboard ini menyajikan data pemantauan dan implementasi kegiatan Sanggala Corridor Project yang dikelompokkan ke dalam empat bidang: perlindungan hutan, keanekaragaman hayati, implementasi proyek, serta kesehatan, keselamatan, dan lingkungan (HSE).

## 1. Perlindungan Hutan dan Pengendalian Kebakaran

| Halaman | Isi |
|---|---|
| [Fire and Forest Patrol Protection](patrol-summary.html) | Ringkasan patroli: jumlah hari patroli, cakupan area (ha), panjang rute (km), *Fire Danger Rating*, komposisi temuan patroli, pemantauan kebakaran, deteksi aktivitas ilegal, dan temuan biodiversitas selama patroli. |
| [Fire Alert](monitoring-fire-event.html) | Peta sebaran titik api, data titik api terbaru, kondisi cuaca terkini, dan prediksi cuaca. |
| [Perbandingan Titik Api](pantauan-titik-api.html) | Perbandingan data historis titik api di area Sanggala. |
| [Satellite Tracker](satellite-tracker.html) | Pemantauan titik panas (*hotspot*) satelit di wilayah Kalimantan Barat. |
| [Land Clearing Alert](land-clearing-alert.html) | Titik pembukaan lahan berdasarkan *Integrated Disturbance Alert* Global Forest Watch. |
| [Community Fire Management](community-fire-management.html) | Hasil penggalian aspirasi masyarakat terkait pengendalian dan mitigasi kebakaran hutan dan lahan. |
| [Weather](weather.html) | Citra cuaca satelit, prediksi cuaca BMKG, dan segala hal yang berkaitan dengan itu di sekitaran area CMI. |

## 2. Keanekaragaman Hayati

| Halaman | Isi |
|---|---|
| [Biodiversity Summary](biodiversity-summary.html) | Menampilkan ringkasan data monitoring biodiversitas, meliputi Jumlah titik monitoring, cakupan patroli, kamera jebak dan perekam bioakustik terpasang, jumlah spesies terdeteksi dan spesies terancam, sebaran *trigger species* dan predator puncak, statistik deteksi per kelas dan per spesies, serta catatan perburuan. |
| [Camera Trap](cameratrap-monitoring.html) | Menampilkan data temuan camera trap, dashboard berisi Peta grid kamera jebak dengan intensitas deteksi, lokasi kamera, dan tutupan lahan (LULC 2023); rincian per grid berupa deteksi per kelas. |
| [Bioacoustic](bioacoustic-monitoring.html) | Menampilkan data temuan bioacoustic, dashboard berisi Peta grid perekam bioakustik dengan intensitas deteksi; rincian per grid berupa deteksi per kelas. |

## 3. Implementasi Proyek

| Halaman | Isi |
|---|---|
| [Planting Monitoring](planting.html) | Total lahan program (agroforestri, reforestasi, dan *enrichment* ENP/ENL), jumlah petani terdaftar, jumlah tanaman, peta lahan garapan dan KTH terdaftar, informasi rinci per lahan, progres penanaman per tahun, jenis tanaman yang ditanam, partisipasi lahan bulanan/mingguan, serta pembayaran insentif program. |
| [Planting Summary](planting-summary.html) | Ringkasan luas lahan, jumlah peserta unik, capaian implementasi ARR (*area planted* dan *area restored*), sebaran lahan program, serta stok dan distribusi bibit. |
| [ARR](arr.html) | Capaian luas terhadap target, rincian sub-program, petani terdaftar, partisipasi lahan, status implementasi, progres penanaman, jenis tanaman, progres pembayaran insentif per tahap, program tahunan, serta luas lahan, progres intervensi, dan rekapitulasi per KTH. |
| [Nursery](nursery.html) | Alur proses persemaian per tipe, komposisi stok bibit per jenis, jumlah bibit per usia, *survival rate* per jenis, serta tipe dan jenis tanaman yang dimanfaatkan. |
| [Monitoring Penanaman](penanaman-program.html) | Luas terdaftar dan jumlah petani, serta rincian per petani: desa, luas, tanggal bergabung, tanggal penanaman, penambahan tanaman, dan komposisi jenis tanaman. |
| [KTH](kth.html) | Profil Kelompok Tani Hutan, meliputi susunan pengurus dan dokumentasi kegiatan. |
| [Daftar Peserta Program](daftar-peserta-program.html) | Daftar lahan peserta agroforestri dan reforestasi beserta peta dan rincian tanamannya. Filter: program, status, dan desa. |
| [Rencana Pola Wanatani](Pola.html) | Peta rencana tanam, zona pengelolaan, komposisi jenis, simulasi pertumbuhan dan stok karbon, arus kas, kesesuaian jenis, kelas lereng, serta ringkasan lahan dan rincian per jenis. |

## 4. Health, Safety & Environment

| Halaman | Isi |
|---|---|
